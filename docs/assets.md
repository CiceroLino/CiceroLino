# Origem dos assets

- `public/images/chronodex.webp`: captura real de
  <https://chronodex-planner.vercel.app/>, em contexto de navegador isolado, sem dados pessoais.
  Resolução: 1440 × 1000. Projeto: <https://github.com/CiceroLino/chronodex>.
- `public/images/liferpg.webp`: captura real de um build web local de LifeRPG,
  criado em cópia temporária do repositório, com dados locais vazios.
  Resolução: 1440 × 1000. Projeto: <https://github.com/CiceroLino/LifeRPG>.
  A captura não representa uma aplicação web publicada; o card aponta ao código.
- `public/favicon.svg`: monograma vetorial CL criado para este portfólio.
- `public/social-card.svg`: composição vetorial original de compartilhamento,
  renderizada em `public/social-card.png` pelo script do projeto.

Os textos dos estudos de caso foram conferidos nos READMEs dos projetos e,
para LifeRPG, no guia de arquitetura local. Não incluem métricas, empregadores,
títulos acadêmicos ou resultados comerciais não documentados.
